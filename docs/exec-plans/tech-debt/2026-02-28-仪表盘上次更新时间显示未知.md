# 仪表盘上次更新时间显示未知

> 状态: ✅ 已解决  
> 创建时间: 2026-02-28  
> 解决时间: 2026-02-28  
> 严重程度: 🟡 中

## 问题描述

仪表盘中"距上次更新"显示"未知"，但"最近上传"模块有数据。

## 根因分析

**问题 1**: 前端代码没有处理 `metadata.lastUpdated` 字段

后端在 `tg-recent-activity.js` 中设置了 `localData.metadata.lastUpdated = new Date().toISOString()`，但前端 `HomePanel.vue` 中的时间显示逻辑只检查以下字段：

1. `metadata.anchor.date`
2. `metadata.currentAnchor.date`
3. `metadata.referenceFile.date`

没有检查 `metadata.lastUpdated`，导致当 anchor 等字段不存在时，显示"未知"。

**问题 2**: 回溯限制太小

`BACKWARD_LIMIT = 2000` 限制只回溯最近 2000 条消息，在消息量大的群组中可能找不到整合包。

## 修复方案

### 修复 1: 添加对 metadata.lastUpdated 的处理

在 `HomePanel.vue` 中添加兜底逻辑：

```javascript
// 优先使用新的 anchor 日期，向后兼容 currentAnchor 和 referenceFile
const metadata = recentActivity.data?.metadata;
if (metadata?.anchor) {
  const refDate = metadata.anchor.date;
  daysSinceUpdate.value = getDaysSince(refDate);
} else if (metadata?.currentAnchor) {
  const refDate = metadata.currentAnchor.date;
  daysSinceUpdate.value = getDaysSince(refDate);
} else if (metadata?.referenceFile) {
  const refDate = metadata.referenceFile.date;
  daysSinceUpdate.value = getDaysSince(refDate);
} else if (metadata?.lastUpdated) {
  // 兜底：使用 lastUpdated 字段
  daysSinceUpdate.value = getDaysSince(metadata.lastUpdated);
}
```

### 修复 2: 增加回溯限制

将 `BACKWARD_LIMIT` 从 2000 改为 10000：

```javascript
// 修改前
const BACKWARD_LIMIT = 2000; // 限制回溯最近 2000 条消息，避免卡死

// 修改后
const BACKWARD_LIMIT = 10000; // 限制回溯最近 10000 条消息，避免卡死
```
