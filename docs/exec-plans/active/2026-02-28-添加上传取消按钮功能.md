## 目标

1. 对于上传字幕模块添加终止按钮用于防止在发送过程中出现问题

## 验收标准

- [x] 能在发送字幕过程之中使用按钮后能成功停止后续发布就算成功

## 实现内容

### 修改的文件

1. `src/main/utils/telegram-login.js` - 添加取消逻辑
2. `src/preload/index.js` - 暴露 `tgCancelUpload` API
3. `src/renderer/src/components/UploadTool.vue` - 添加取消按钮和状态管理

### 功能说明

- **方案：即时取消（force destroy transport）**
- 点击取消按钮时：
  1. 设置 `uploadCancelled = true`
  2. 强制销毁 transport: `telegramClient._sender?._transport?.destroy()`
- 上传循环中每 200ms 检测一次取消标志
- 检测到取消时立即 reject，停止当前上传

### 取消检测点

1. 文件循环开始时
2. 步骤1 while 循环每次重试前
3. 步骤2 while 循环每次重试前
4. 步骤2 Promise 中每 200ms 检测
5. catch 中捕获 CANCELLED 错误

### Bug 日志

- 第一次：取消按钮点击后仍然还在上传 → 已在步骤1和步骤2的 while 循环中添加取消检查
- 第二次：取消上传后按钮没有变回来 → 在日志监听器中添加状态检测
- 第三次：按钮切换过慢，无法真正立即取消 → 改用方案3（独立 client）
- 第四次：独立 client 方案仍然不行 → 改用方案1（destroy transport）
- 第五次：取消后仍继续重试 → 在所有循环中添加取消检查 + 200ms 定时检测

### Bug 修复记录

- [x] 修复：上传过程中看不到按钮 → 已将按钮改为 v-if/v-else 条件渲染

- [x] 修复：取消后按钮没有变回来 → 在日志监听器中添加状态检测
