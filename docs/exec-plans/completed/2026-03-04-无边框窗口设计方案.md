# 无边框窗口设计方案（类网易云风格）

> 状态: ✅ 已完成（Phase 1 + Phase 2 + Phase 3）
> 创建时间: 2026-03-04
> 关联代码: `src/main/index.js`、`src/renderer/src/App.vue`

## 背景

你希望页面呈现“类似无边框客户端”的视觉风格（弱化系统窗口边框与标题栏），当前工程在本计划发起时仍使用默认窗口外观：

- `BrowserWindow` 未配置 `frame: false`。
- 顶部区域仍是系统标题栏行为，UI 一体感不足。

## 目标

1. 让应用达到“类无边框 + 自定义顶栏”的桌面客户端体验。
2. 保留窗口基础能力（拖动、缩放、最小化、最大化、关闭）。
3. 降低跨平台风险，优先保证 Windows 可用，再兼容 macOS/Linux。

## 非目标

1. 本阶段不重做业务页面内容布局。
2. 本阶段不强依赖亚克力/毛玻璃等系统特效（可后续增强）。
3. 本阶段不改变现有模块路由与 IPC 业务协议。

## 设计策略（推荐）

采用“两阶段落地”，先做**低风险准无边框**，再做**完整无边框**。

### 方案 A：准无边框（优先推荐，低风险）

核心思路：保留系统窗口框架能力，使用自定义顶栏覆盖视觉，做到“看起来无边框”。

- 主进程：启用 `titleBarOverlay`（按平台条件开启）。
- 渲染层：实现自定义 Header（含窗口控制按钮）。
- 顶栏拖拽：使用 `-webkit-app-region: drag`；按钮区域 `no-drag`。

优点：

1. 缩放与边缘拖拽兼容性更稳。
2. 多平台差异更小，回归成本低。
3. 更适合作为第一版验收基线。

### 方案 B：完整无边框（第二阶段）

核心思路：主窗口使用 `frame: false`，所有窗口交互由应用层接管。

- 主进程：切换 `BrowserWindow` 到无框配置。
- 渲染层：实现完整自绘标题栏 + 阴影/圆角视觉壳层。
- IPC：补齐窗口状态同步（最大化、还原、是否可拖动边界）。

风险：

1. Windows 上边缘缩放、阴影与贴边行为需要额外处理。
2. 多显示器与 DPI 缩放场景测试量明显上升。

## 信息架构与交互规范

### 1) 顶栏结构

- 左侧：应用标识 + 当前页面标题。
- 中间：可扩展操作区（后续可放全局搜索/状态）。
- 右侧：最小化、最大化/还原、关闭按钮。

### 2) 拖拽规则

- 整个顶栏默认可拖动。
- 所有可点击控件（按钮、输入框、菜单）显式声明 `no-drag`。
- 页面滚动区与内容区一律禁止 drag，避免误触。

### 3) 窗口控制交互

- 双击顶栏空白区：最大化/还原。
- 最大化时自动调整内容圆角与边距，避免贴边裁切。
- 关闭按钮采用危险态视觉（红色 hover），其余按钮中性。

## 风险与应对

1. **风险**：无边框后拖拽区域与点击区域冲突。  
   **应对**：建立统一 `drag/no-drag` CSS 规范并集中复用。
2. **风险**：不同平台窗口行为不一致。  
   **应对**：窗口参数按平台分支，优先确保 Windows 稳定。
3. **风险**：引入后用户习惯不一致。  
   **应对**：提供可回退配置（保留系统边框模式开关）。
