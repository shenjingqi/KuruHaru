## 目录结构

```

├── active/          # 进行中的计划
│   └── *.md         # 每个计划一个文件
├── completed/       # 已完成的计划
│   └── *.md

    └── *.md
```

---

## 使用方法

### 创建新计划

在 `active/` 目录下创建新文件，命名格式：

```
YYYY-MM-DD-[计划名称].md
```

### 计划模板

```markdown
# [计划名称]

> 状态: 🔄 进行中 / ✅ 已完成  
> 创建时间: YYYY-MM-DD  
> 预计完成: YYYY-MM-DD

## 目标

[简明描述要达成的目标]

## 任务列表

- [ ] 任务 1
- [ ] 任务 2

## 进度记录

### YYYY-MM-DD

- 记录当天的进展

## 决策日志

### YYYY-MM-DD

- [决定]: [原因]
```
