## 产品愿景

ASMR 内容管理 + Telegram 频道发布工具的桌面应用

---

## 业务背景

### 目标用户

- ASMR 内容爱好者
- Telegram 频道管理员
- 音声/字幕汉化工作者

### 业务场景

用户通过以下完整工作流程发布 ASMR 内容到 Telegram 频道：

```
筛选计划 → 资源下载 → 音声翻译 → 频道上传 → 数据清理 → 周期发包
```

### 核心价值

1. **自动化**: 减少人工重复劳动
2. **去重**: 避免重复发布
3. **效率**: 批量处理提高效率

---

## 业务边界（重要）

### 属于本项目

| 业务域     | 功能                             |
| ---------- | -------------------------------- |
| 计划与筛选 | RJ号筛选、标签精选、汉化数据同步 |
| 资源下载   | ASMR 音声下载任务、Aria2 推送    |
| 音声翻译   | Whisper 语音转字幕、字幕格式转换 |
| 频道上传   | Telegram 上传、投递管理          |
| 数据清理   | 本地清理、云端清理               |
| 周期发包   | 最近上传记录下载                 |

### 不属于本项目（外部工具）

| 业务域     | 说明                                                   |
| ---------- | ------------------------------------------------------ |
| 页面内勾选 | 站点页面内的树状文件人工勾选下载，仍建议使用浏览器脚本 |
| Aria2 环境 | Aria2 需单独安装并由用户维护运行状态                   |

> ⚠️ **注意**: KuruHaru 现已内置批量音声下载任务生成与 Aria2 推送；浏览器脚本保留为页面内手动挑选下载的补充方案。
