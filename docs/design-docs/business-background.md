# 业务背景

> 状态: ✅ 稳定  
> 最后更新: 2026-02-26

本文档描述 KuruHaru 项目的业务背景、用户需求和产品定位。

---

## 项目背景

### 业务起源

KuruHaru 诞生于 ASMR 内容汉化 Telegram 频道的运营需求。运营者需要：

1. **高效筛选内容** - 从 ASMR 网站海量作品中筛选目标作品
2. **批量处理** - 批量生成字幕、上传至 Telegram
3. **去重管理** - 避免重复发布，确保更新计划准确

---

## 目标用户

| 用户类型            | 需求                     |
| ------------------- | ------------------------ |
| Telegram 频道管理员 | 批量发布 ASMR 内容到频道 |
| ASMR 汉化工作者     | 语音转字幕、批量处理     |
| 内容运营者          | 计划管理、去重、数据清理 |

---

## 用户画像

### 典型用户：Telegram 频道运营者

- 运营 ASMR 汉化频道
- 需要定期更新内容（每日/每周）
- 使用 Windows 系统
- 熟悉 Telegram Bot 操作
- 具备一定的技术能力（配置 Whisper、代理等）

---

## 核心需求

### 需求优先级

| 优先级 | 需求        | 描述                     |
| ------ | ----------- | ------------------------ |
| P0     | 计划筛选    | 从 ASMR 网站筛选目标作品 |
| P0     | 频道上传    | 上传字幕 zip 到 Telegram |
| P0     | 数据清理    | 清理已完成的任务         |
| P1     | 语音转字幕  | Whisper 批量生成字幕     |
| P1     | 最近上传    | 查看频道历史发布记录     |
| P2     | 高级搜索    | 多条件筛选作品           |
| P2     | RJ 精确查找 | 按 RJ 号精准定位作品     |

---

## 业务痛点

### 痛点 1：筛选效率低

**问题**：人工从 ASMR 网站筛选作品耗时

**解决**：提供标签精选、RJ 号筛选、高级搜索工具

### 痛点 2：重复发布

**问题**：多管理员协作容易"撞车"

**解决**：云端清理功能自动同步频道最近发布记录

### 痛点 3：手动上传繁琐

**问题**：逐个手动上传字幕 zip 效率低

**解决**：智能扫描文件夹，批量上传

---

## 业务价值

| 价值点   | 说明                 |
| -------- | -------------------- |
| 自动化   | 减少人工重复劳动     |
| 效率提升 | 批量处理 vs 手动操作 |
| 去重保障 | 避免重复发布         |
| 协作友好 | 多管理员数据同步     |

---

## 竞品对比

| 方案         | 优点               | 缺点             |
| ------------ | ------------------ | ---------------- |
| 人工操作     | 灵活               | 效率低、易出错   |
| 第三方工具   | 开箱即用           | 功能分散、不定制 |
| **KuruHaru** | **一体化、定制化** | **需本地部署**   |
