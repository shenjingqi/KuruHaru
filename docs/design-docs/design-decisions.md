## 决策日志

### 2026-02-26: 向前依赖架构

> 状态: 已实现

**背景**: 需要建立清晰的代码分层，避免循环依赖和混乱的模块关系。

**决策**: 采用七层架构

```
Types → Config → Repo → DataAccess → Service → Runtime → UI
```

**影响**:

- ESLint 规则已配置
- AGENTS.md 已更新
- 代码组织更加清晰

---

### 2026-02-26: HTTP 客户端统一代理

> 状态: 已实现

**背景**: 项目中直接使用 axios 访问 ASMR 和 Telegram API，无法统一管理代理。

**决策**:

- 创建 httpClient 模块
- 强制所有网络请求通过 httpClient
- ESLint 禁止直接使用 axios

**影响**:

- 69 asmr-login.js 已改用 getAsmrClient()
- 所有 TG/ASMR 请求统一走代理

---

### 2026-02-26: 业务边界划分

> 状态: 已实现

**背景**: 需要明确哪些功能属于本项目，哪些是外部工具。

**决策**:

- 资源下载（Greasyfork 脚本）不属于本项目
- 音声翻译、频道上传、数据清理属于本项目

**影响**:

- 创建了 business-boundary.md
- 文档明确了业务边界
