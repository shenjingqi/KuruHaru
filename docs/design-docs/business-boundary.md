# 业务边界

> 状态: ✅ 稳定  
> 最后更新: 2026-03-04

本文档明确 KuruHaru 项目的业务边界，区分本项目负责范围与外部依赖。

---

## 边界原则

1. **本桌面应用负责**：本地数据处理、UI 交互、API 调用。
2. **外部工具负责**：需要浏览器环境或操作系统级别的操作。
3. **用户手动操作**：复杂且变化频繁、难以稳定自动化的流程。

## 详细边界说明

### 属于本项目（Desktop App）

#### 1. 计划与筛选

```javascript
// 本项目功能
- asmr-localization.js: 抓取 ASMR 网站数据
- 高级搜索: 多条件筛选
- RJ 号筛选: 精准定位作品
- 汉化列表: 同步统计数据
```

#### 2. 音声翻译

```javascript
// 本项目功能
- whisper.js: 调用本地 Whisper 生成字幕
- 打包: 生成 zip 压缩包
```

#### 3. 频道上传

```javascript
// 本项目功能
- telegram-login.js: Telegram 登录与串行上传
- tg-recent-activity.js: 最近活动读取、下载、缓存管理
```

#### 4. 频道检索与治理

```javascript
// 本项目功能
- tg-search-bot.js: Bot 搜索、历史索引同步、启动自动同步
- tg-rj-duplicates.js: 重复配对扫描 + 安全删除链路
```

#### 5. 数据清理

```javascript
// 本项目功能
- 本地扫描: 读取本地文件列表并比对 RJ/VJ/BJ
- 云端同步: 获取频道最近发布记录并用于清理
```

---

### 不属于本项目（外部工具）

#### 1. 资源下载

> ⚠️ **重要边界**：下载功能不属于本项目

**原因**：

- ASMR 网站音频下载需要登录认证。
- 需要处理复杂的 SE 命名逻辑。
- 浏览器环境更适合（Cookie 管理、限流处理）。

**外部解决方案**：

| 工具            | 用途     | 链接                                                               |
| --------------- | -------- | ------------------------------------------------------------------ |
| Greasyfork 脚本 | 一键下载 | [ASMROnline 一键下载](https://greasyfork.org/zh-CN/scripts/563902) |
| Aria2           | 下载加速 | 需单独安装配置                                                     |

**工作流程**：

```text
用户使用 Greasyfork 脚本 + Aria2 下载
        ↓
下载完成后的 .wav 文件存放至媒体目录
        ↓
KuruHaru 扫描目录进行后续处理
```
