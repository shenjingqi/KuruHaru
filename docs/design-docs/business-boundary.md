# 业务边界

> 状态: ✅ 稳定  
> 最后更新: 2026-04-13

本文档明确 KuruHaru 项目的业务边界，区分本项目负责范围与外部依赖。

---

## 边界原则

1. **本桌面应用负责**：本地数据处理、UI 交互、API 调用。
2. **外部工具负责**：需要浏览器环境或操作系统级别的操作。
3. **用户手动操作**：复杂且变化频繁、难以稳定自动化的流程。

## 详细边界说明

### 属于本项目（Desktop App）

#### 1. 计划与筛选

```javascript
// 本项目功能
- asmr-localization.js: 抓取 ASMR 网站数据
- 高级搜索: 多条件筛选
- RJ 号筛选: 精准定位作品
- 汉化列表: 同步统计数据
```

#### 2. 音声翻译

```javascript
// 本项目功能
- whisper.js: 调用本地 Whisper 生成字幕
- 打包: 生成 zip 压缩包
```

#### 2.1 资源下载任务

```javascript
// 本项目功能
- asmr-audio-downloader.js: 输入 RJ/VJ/BJ/数字 ID/作品链接，生成音频下载任务
- asmr-core/audio-download-utils.js: 轨道解析、黑名单过滤、指纹去重、超长路径拦截
- Tools.vue: 在桌面端直接生成 aria2_tasks.txt / manual_review.txt，并可推送到 Aria2
```

#### 3. 频道上传

```javascript
// 本项目功能
- telegram-login.js: Telegram 登录与串行上传
- tg-recent-activity.js: 最近活动读取、下载、缓存管理
```

#### 4. 频道检索与治理

```javascript
// 本项目功能
- tg-search-bot.js: Bot 搜索、历史索引同步、启动自动同步
- tg-rj-duplicates.js: 重复配对扫描 + 安全删除链路
```

#### 5. 数据清理

```javascript
// 本项目功能
- 本地扫描: 读取本地文件列表并比对 RJ/VJ/BJ
- 云端同步: 获取频道最近发布记录并用于清理
```

---

### 不属于本项目（外部工具）

#### 1. 浏览器内手动挑选下载

> ⚠️ **仍然属于外部工具能力**：如果需要在站点页面里人工勾选树状文件、按页面即时挑选下载，仍建议使用浏览器脚本。

**外部解决方案**：

| 工具            | 用途                 | 链接                                                               |
| --------------- | -------------------- | ------------------------------------------------------------------ |
| Greasyfork 脚本 | 页面内手动勾选下载   | [ASMROnline 一键下载](https://greasyfork.org/zh-CN/scripts/563902) |
| Aria2           | 下载加速 / 队列执行  | 需单独安装配置                                                     |

**当前工作流程**：

```text
用户在 KuruHaru 中输入 RJ/VJ/BJ / 链接生成下载任务
        ↓
可选推送到本机 Aria2，或仅导出 aria2_tasks.txt / manual_review.txt
        ↓
下载完成后的音频存放至目标目录
        ↓
KuruHaru 继续执行转写、打包、上传等后续处理
```
