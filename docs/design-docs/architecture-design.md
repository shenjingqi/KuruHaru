# 架构设计

> 状态: ✅ 稳定  
> WR|> 最后更新: 2026-02-28

## 设计目标

为 KuruHaru 应用建立一个清晰、可扩展的架构，使 AI Agent 能够：

1. 理解代码组织方式
2. 遵循分层约束进行开发
3. 自主导航和定位相关模块
4. 明确业务边界

---

## 核心分层

```
┌─────────────────────────────────────────────┐
│              Renderer (Vue 3)               │
│    只能通过 window.api 调用主进程功能       │
└──────────────────┬──────────────────────────┘
                   │ IPC
┌──────────────────▼──────────────────────────┐
│              Preload (桥接层)               │
│    暴露安全的 API 给 renderer               │
└──────────────────┬──────────────────────────┘
                   │
┌──────────────────▼──────────────────────────┐
│           Main Process (Node.js)            │
│  ┌─────────────────────────────────────────┐│

│  └────────────────┬────────────────────────┘│
│                   │                         │

│  │Modules│    Utils      │ Config │        │
│  │        │               │        │        │
│  └────────┴───────────────┴────────┘        │
└─────────────────────────────────────────────┘
```

## 各层职责

### Renderer (渲染进程)

- Vue 3 组件 UI 展示
- 用户交互处理
- 状态管理 (Pinia)
- **禁止**: 直接使用 Node.js 模块、文件系统

### Preload (预加载脚本)

- 安全桥接层
- 暴露有限 API 给 renderer
- 输入验证

### Main (主进程)

- 窗口管理、系统托盘
- IPC 处理器注册
- 业务逻辑模块
- 文件系统操作

## 依赖规则

```
Renderer ──► Preload ──► Main
                        │
                   ┌────┴────┐
                   │ Modules │
                   └────┬────┘
                        │
                   ┌────┴────┐
                   │  Utils  │
                   └────┬────┘
                        │
                   ┌────┴────┐
                   │ Config  │
                   └─────────┘
```

**强制约束**:

- ❌ Renderer 不能引用 electron/fs/path 等模块
- ❌ Config 模块不能包含业务逻辑
- ❌ Utils 不能引用 Modules
- ❌ 禁止直接使用 axios，必须通过 httpClient
- ✅ 所有跨层调用必须通过 IPC
- ✅ 所有网络请求必须使用 httpClient（带代理支持）

---

## HTTP 代理规则

所有访问 ASMR.one 和 Telegram 的网络请求**必须**通过 `httpClient` 模块：

```javascript
// ✅ 正确 - 使用 httpClient
import { getAsmrClient, getTgClient } from "./httpClient";
const client = await getAsmrClient();
const response = await client.get("/api/xxx");

// ❌ 错误 - 直接使用 axios
import axios from "axios"; // 禁止！
```
